## 主要偏差

1. **缺少独立审核。** 147 条没有投票，147 条带有 CURRENT_VALIDATION_MISSING。这批记录是执行结束后保守转人工的结果，不能计入“实质审核完成率”，更不能据此计算审核准确率。
2. **规划动作与执行契约不匹配。** 45 条出现人工降级，其中 27 条由动作契约错误触发，18 条由连接失败或超时触发。102 次 inspect_context 因引用不在当前已验证目录而被拦截，实例包括把 `current` 当成 evidence_id。
3. **本体扩展前置顺序未被规划器正确执行。** 79 次 request_ontology_extension 都缺少当前独立来源支持共识。程序拦截符合方案；规划器应先查完整冻结本体、组织来源支持审核，再依据共识请求扩展。单靠规划器声称“原文支持”不能满足前置条件。
4. **预算消耗没有转化为完整审核。** 17 条以规划步数耗尽结束，18 条以 token 预算耗尽结束。实际产生投票的 7 条均以 token 预算耗尽结束；其中 4 条已有来源支持共识，但未继续形成完整的扩展或准入路径。
5. **上游身份和本体覆盖问题较多。** 146 条出现 CANDIDATE_IDENTITY_UNRESOLVED；本地冻结本体复算为 unknown 143 条、fail 8 条、pass 3 条。这些问题需要分别处理，不能把未匹配或身份未规范化解释成事实错误。
