# 本轮评价指标及计算口径

本轮计划40条，统一隔离2条未知结果候选，38条进入比较。使用GPT参考标签；未做独立人工准确率评估。所有运行结果按完整40条总体报告，隔离项单列。

## 维度一致率

一致率 = 与GPT标签相同数 / 双方均给出明确标签数。判定覆盖率 = 模型明确判定数 / 未隔离且GPT标签已知数。参考标签已知的可评样本为36条；B0没有维度判断。

| 组别 | 来源一致率 | 来源判定覆盖率 | 表达一致率 | 表达判定覆盖率 |
|---|---:|---:|---:|---:|
| B0 全部保留 | 不适用（分母为0） | 0/36 = 0.0% | 不适用（分母为0） | 0/36 = 0.0% |
| B1 DeepSeek | 22/33 = 66.7% | 33/36 = 91.7% | 16/23 = 69.6% | 23/36 = 63.9% |
| B2 多数票 | 27/35 = 77.1% | 35/36 = 97.2% | 21/28 = 75.0% | 28/36 = 77.8% |
| B3 固定流程 | 16/23 = 69.6% | 23/36 = 63.9% | 21/27 = 77.8% | 27/36 = 75.0% |
| 完整Agent | 16/23 = 69.6% | 23/36 = 63.9% | 21/27 = 77.8% | 27/36 = 75.0% |

一致率的分母因方法而异，不能只看百分比排名；必须结合判定覆盖率。技术未完成样本中已经合法形成的分维度观察仍可参与对应维度计分，它不代表该条整体验收完成。

## 运行结果指标（分母均为40）

| 组别 | 自动决策覆盖率 | 完成后人工建议率 | 技术未完成率 | 未知候选隔离率 |
|---|---:|---:|---:|---:|
| B0 全部保留 | 38/40 = 95.0% | 0/40 = 0.0% | 0/40 = 0.0% | 2/40 = 5.0% |

自动决策覆盖率 =（自动保留建议 + 明确拒绝建议）/40。这里是研究建议，实际入库写入为0。人工建议率只计流程完成后仍需人工判断的样本；技术未完成和隔离不会混入人工建议数。四类互斥并合计100%。人工建议率较低可能由技术失败较多造成，不能直接解释为节省人工。

## 尚无可用数值的主质量指标

- 准入精确率：正确自动通过数 / 有参考裁决的自动通过数。
- 正确候选保留率：正确自动通过数 / 参考确认可接纳数。
- 错误放行率：自动通过的不可接纳数 / 参考确认不可接纳数。

当前GPT标注的准入偏好不等于已定义的二值准入真值，40条也均未完成本体映射，因此上述三项保留为未评估，不能填0或套用来源支持标签。若后续建立明确的GPT二值准入参考，可以计算相对该GPT参考的三项指标，并继续注明不是独立人工真值。
