## 已完成

- 显示候选总数、已开始、处理结束、审核席位齐全、运行中及已有意见分歧。历史1条试跑与29条续跑按各自清单统计；没有完整清单的批次明确提示仅统计已有记录。

- 九维意见矩阵可以逐项打开公开说明、证据ID及冻结原文；字段补正可以查看错误路径、实际/预期类型、原响应、补丁和合并结果。
- 程序汇总单独显示。不同候选版本、轮次、证据包或本体绑定的票不串用；迟到响应不会被监控页自动采纳为最终决定。
- 当前详情在运行时约2秒刷新，结束后降低频率；批次概览约5秒刷新。切换页面、数据源、候选、轮次及浏览器隐藏时取消过期请求；增量游标避免重复传输相同快照。人工审核草稿与监控分属独立组件。
