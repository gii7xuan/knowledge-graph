## 标签与标注材料

首批提供一个可直接填写的 Excel 模板、逐条 HTML 证据卡、两份独立审核人的空白 JSON、冻结本体参考和标注说明。Excel 的填写页保留原候选，六项标签为来源支持、表达质量、已有映射、本体覆盖、知识范围、操作偏好，并记录支持/反驳证据 ID、理由、修改建议、审核人、时间、实际秒数和是否看过模型审核结论。

每名审核人另存一份模板并独立填写。两份原标及分歧都保留；人工裁决在独立 adjudication 对象中记录。空白不等于未知，也不等于零耗时。表格回读只生成待裁决的原始声明，不能自动产生金标准或模型可靠性统计。

模态试标规范区分认知可能性、能力/许可、假设、近似和定义性陈述；“可近似看成”须保留近似含义，结合谓词、完整句子与限定附着判断，不按单个“可”机械赋值。该规范没有为本包预填任何答案。

人工与后续方法使用完全相同的冻结初始证据包，人工可读的完整片段也作为 current_chunk 来源材料放入方法输入。未展示任何审核票、权重或最终操作。候选的原始抽取语义字段属于待核对对象，不能把这些字段视为正确结论。

## 需要保留的实际问题

160 条候选目前均未绑定正式关系 ID，不能把这一状态当作“160 条事实错误”或“本体完全不覆盖”。正式 ID、类型提示、语义等价与本体覆盖需分别核实。当前冻结本体含 48 个关系，来自此前开发材料；对新的双语基础概念有明显覆盖/映射准备问题。因此这批先用于来源、表达和本体覆盖试标，不能直接用全四维准入率宣称完整方法优劣。共享定义或本体准备如需调整，应对所有组共同冻结，再开展公平对照。

另有 42 条候选保留了原抽取中的契约问题，例如限定值与状态不一致、非法模态枚举、未完整声明的 literal。没有静默补成正确候选，也没有按审核是否容易通过筛掉这些问题。具体计数在 intake_summary.json。它们需要与语义错误、来源不足和映射缺失分开统计。
