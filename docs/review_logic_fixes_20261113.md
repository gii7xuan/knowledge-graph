| 位置 | 原有错误 | 修复后的行为 |
|---|---|---|
| `review_agent/review_axes.py::aggregate_axes` | 无条件把非空反证列表视为分歧，三席一致判为 contradicted 且引用真实反证时也被降为 unresolved；来源维度还只列支持证据。 | 完整、多样性合格的委员会一致否定可以保留 contradicted，并保留反证引用。缺席、支持与否定混合、显式未解决冲突仍保持未决。 |
| `review_agent/request_execution.py::judge_typed` | 后续恢复具有任务专用反馈，同轮重试却只有通用提示；中间出现已知 HTTP 失败时，上一份契约纠错反馈被遗忘。对畸形引用的纠错代码还可能再次抛错。 | 同轮重试与后续恢复共用反馈生成逻辑；已知传输失败保留最近一次契约纠错要求。支持字典和 JSON 字符串形式的原回复，文档 ID 类型错误也能生成反馈。有效修订/反对票继续缓存，未知请求继续禁止重发。 |
| `evaluation/split_integrity.py` | 只按重叠片段或重复事实分组，同一文档的不重叠内容、不同版本及改名后的相同原文可能跨组；头实体和关系精确匹配也让大小写、边缘空白变化逃过重复检查。 | 按文档 ID、原文内容哈希和重复事实合并隔离组；独立测试缺少来源 ID 或版本时拒绝通过。重复比较统一去除边缘空白、忽略大小写。隔离规则版本更新为 `source_fact_split_v2`。 |
