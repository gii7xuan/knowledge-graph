# 四维审核结论与独立处理状态

默认新审核使用 `validator_response_v7`。保留九项细查，新增结构化的 `expression_findings`；程序据此生成 `review_axes`，不再将事实、表达、本体和任务范围汇为一个通过率。

|维度|记录内容|状态|
|---|---|---|
|原文支持|实体、关系、方向、条件、频率、模态是否受原文支持|支持、矛盾、证据不足、尚无一致结论|
|表达规范|字段位置、重复限定、复合实体及实质语义问题|规范、可无损规范化、需要语义修订、待核验|
|本体映射|正式关系定义、实体指称及类型约束|有效、未分配、冲突、上下文不完整|
|收录范围|冻结项目政策下是否收录该知识|收录、排除、边界不清|

`core_source_support_result` 继续保留基本关系的独立诊断，不能替代包含方向和限定的原文支持维度。席位缺失、模型家族不足、响应不合法、未解决的实质反证均不能形成支持结论。三席意见齐全与允许准入分别记录。

## 规范化的边界

表示性问题必须通过结构化字段声明，不能靠公开说明中的“只是格式问题”“无损”等措辞判断。当前仅验证以下两种有界操作，并记录待办，不自动修改候选：

1. 字段归类：`retain_qualifier` 保留原字段中的完整限定值。程序核对当前候选、明确提取状态、有效原文锚点及原文中的确切限定内容。例如“常常”保留在 applicability 中，可进入规范化待办而不构成事实错误；不会删除该频率或改成无条件断言。
2. 重复限定：`remove_duplicate_qualifier` 仅处理谓词边界上与 qualifiers 中完全相同的重复内容。限定值仍须留在 qualifiers，去重后谓词不得为空。

否定、条件、方向或模态的改变不属于上述规范化。极性和模态字段不允许以这种方式重新分类。复合实体拆分需要独立审查，不自动认定为无损。规范化方案不能引用冻结证据包外的 ID，也不能由字段纠错服务改写其判断。

现有图谱投影保存 `qualifiers_json`，存在条件、适用性、量词等限定时不生成无条件直连边。专项回归覆盖频率保留及去重后谓词为空等边界。规范化待办仍会阻止自动准入，必须按新版本审核流程完成实际修改与核验。

## 程序状态与界面

决策中保存四维 `review_axes` 和全部 `pending_actions`。主要处理状态分别是 `semantic_revision_required`、`normalization_required`、`evidence_insufficient`、`source_review`、`mapping_review`、`scope_review`、`excluded_by_scope`、`review_incomplete`。同一候选可以同时待规范化和待映射，不能因主队列优先级丢掉另一项义务。模型分歧和技术缺席分别处理，不自动改叫证据不足。

三元组审核详情、Agent 审核监控均展示四张结论卡；监控可分别筛选语义修订、旧版未分类修订、无损规范化、证据不足、映射和范围。九项细查、模型公开说明和证据仍可查阅。

旧审核票、冻结提示和原决定不重新分类。历史界面只投影已有结论，并明确标注“旧版：完整忠实”或“待区分修订类型”；没有独立范围结论时显示边界不清。新政策、Schema、提示、规范化判断及范围政策进入冻结提案与请求身份。历史补审继续使用原契约。
