# V8 审核下一轮修改记录

本轮复用原有三席审核、四维聚合、任务队列和修订服务。生产自动准入、自动应用修订、本体发布和图谱导入保持关闭。没有新增模型席位、投票权重或 Agent 层级。

## 复现入口

在项目根目录，使用现有 knowledge Python 环境。每个新运行目录必须未存在；不重启结果未知的网络任务。

```powershell
# 零模型调用，使用新目录；相同代码/输入对同目录重算可验证幂等。
& 'D:\miniconda3\envs\knowledge\python.exe' -X utf8 -B -m runs.revalidate_v8

# 新7条完整流程。固定三席，420秒/候选、18次调用预算、一次格式修复上限。
& 'D:\miniconda3\envs\knowledge\python.exe' -X utf8 -B -m runs.regress_v8 --mode smoke --output outputs/<全新冒烟目录> --run

# 全30条入口：要求当前代码版本与通过的冒烟门槛一致。
& 'D:\miniconda3\envs\knowledge\python.exe' -X utf8 -B -m runs.regress_v8 --mode full --smoke-gate outputs/<通过门槛的冒烟目录> --output outputs/<全新30条目录> --run

# 只读封存报告、当前材料与人工重标模板。
& 'D:\miniconda3\envs\knowledge\python.exe' -X utf8 -B -m runs.report_v8_regression --directory outputs/<完整回归目录>

# 精确独立批准的草案才可在新副本应用；拆分使用 --group-id。
& 'D:\miniconda3\envs\knowledge\python.exe' -X utf8 -B -m runs.shadow_revision_v8 --source outputs/<来源实验>/review.sqlite3 --output outputs/<全新影子目录> --draft-id <已独立批准草案> --run
```

省略 regress/shadow 命令的 `--run` 仅准备实验，不发送模型请求。模型目的地沿用已授权的 Qwen/Gemma 网关和 DeepSeek；不输出密钥。实际30条复跑应在工程门槛满足后执行，不能将离线重验写成完整新调用。
