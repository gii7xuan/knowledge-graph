## 火炮领域本体构建方案（基于14个顶层类）

---

### 一、本体架构概览

基于14个顶层类，本体将构建一个层级化的知识体系：

```
1. 武器装备 (C_WeaponEquipment)
2. 火炮系统 (C_ArtillerySystem)
3. 火炮部件与机构 (C_ComponentMechanism)
4. 自动机与动作机构 (C_AutomaticMechanism)
5. 弹药与装药 (C_Ammunition)
6. 弹道与射击过程 (C_BallisticsProcess)
7. 动力学对象 (C_DynamicsObject)
8. 设计对象 (C_DesignObject)
9. 性能参数 (C_PerformanceParameter)
10. 材料与工艺 (C_MaterialProcess)
11. 试验、检测与评价 (C_TestEvaluation)
12. 故障、失效与维修 (C_FaultMaintenance)
13. 型号、谱系与装备信息 (C_ModelLineage)
14. 使用环境与应用场景 (C_EnvironmentScenario)
```

### 三、本体使用流程

#### 1. 三元组抽取阶段
- 使用本体中的**类定义**指导实体识别
- 使用**关系定义**约束抽取关系类型
- 使用**属性定义**规范实体属性提取

#### 2. 本体校验阶段
- **类型校验**：检查实体是否属于允许的类
- **关系校验**：检查关系是否在允许的关系集合中
- **粒度校验**：检查实体粒度是否合理（避免过细/过粗）
- **一致性校验**：检查属性值是否符合数据类型和范围

#### 3. 置信度评分阶段
- 基于抽取规则匹配度
- 基于本体约束满足度
- 基于文献支持度

#### 4. Neo4j导入阶段
- 将本体映射为 Neo4j 的 Schema
- 类 → Node Label
- 关系 → Relationship Type
- 属性 → Property Key
